# 任务面板 · Task Sidebar

会话右上角的一个小面板：这一轮到底给模型喂了什么、用到了哪些技能和连接器、有没有在等你处理的事、最后交付了哪些文件，一眼能看到，点一下就能在右侧栏打开原文。

## 出发点

一个会话跑久了，最容易丢的是三件事：**输入了什么**、**用了什么**、**产出了什么**。它们散落在聊天记录里，往上翻要翻很久，翻到了还要再点一次才能看内容。

这个面板把这三件事按会话汇总成一份短清单，并且把「看内容」这一步直接接到右侧栏——面板负责告诉你有什么，右侧栏负责给你看原文。

它有意不做第二份进度表：会话本身的执行过程由官方的任务卡呈现，重复一份只会多一处要维护的真相。

## 面板里有什么

- **输入** —— 本会话你自己发来的最近 20 份附件和最近 30 条 `@` 引用的资料路径，新的排在前面。点图片行展开小图，再点小图可在右侧栏看原图；点 `@` 引用路径在同一侧栏打开受 DSH 支持的文件。上传的非图片附件显示文件名和大小。换轮或重启后仍可从会话记录恢复。
- **技能与连接器** —— 本会话实际调用过的技能和连接器（连接器指 MCP 服务器）。展开技能可看用途简介，点「查看技能文档」在右侧栏打开当前可用的 Markdown 原文。点连接器可展开它在本会话调用过的工具。点「管理」可查看 DSH 全局受管连接器的实时状态与可用工具数，由设置管理的连接器可连接或断开，由插件注册的连接器可重新连接；这些操作影响所有会话，静态配置或仅供某个 Agent 使用的连接器不在管理列表中。
- **待你处理** —— 当前等待的批准、提问或计划审阅。可定位的提问能直接打开，其余事项在聊天底部的输入区处理。
- **输出** —— 本会话最近 60 个明确交付的文件，再次交付同一路径会把记录移到前面。点文件在右侧栏打开预览；已完成或已归档的会话同样可以打开。打不开时原因显示在对应条目下方，并可直接复制路径。分叉会话从自己交付的第一份文件开始记录。

默认所有分组是收起的，标题右侧的数字悬停才显示；面板宽度跟随右侧栏，不会盖住正文。

## 安装

首发版本在 **DeepSeek Harness 0.2.2-rc.5** 上验证。

在 DeepSeek Harness 的插件管理里选择通过 npm 安装，输入 `dsh-task-sidebar`；也可以使用命令行：

```sh
dsh plugin --profile desktop add dsh-task-sidebar
```

桌面版使用 `desktop`，独立 Web 配置可替换为 `web`。如果此前启用过本地版 `@local/dsh-task-sidebar`，请先停用它，避免两套面板同时注册。

## 怎么用

打开一个已有消息的会话，点右上角的清单图标，面板在按钮下方展开；再次点图标、点面板外或按 Esc 收起。之后照常聊天，面板内容会随会话更新。不需要时在插件管理里关掉「任务面板」即可。

## 已知限制

- 只在 0.2.2-rc.5 上验证，DSH 升级后需要复核。
- 在网页版里作为「附件」上传、没有本地路径的非图片文件，只显示文件名和大小，不提供打开入口——这类文件在桌面版通常进「引用」组，可正常打开。
- 右侧栏预览依赖宿主对文件地址的认领：文件不在当前会话目录内、文件已被移走或会话已切换时，面板会说明原因而不是静默失败。
- 连接器管理只覆盖 DSH 全局受管连接器，插件静态注册的、或只服务某个 Agent 的连接器不在其中。

## 兼容性与自检

本版本发布前的检查是包内自检：`npm test` 依次校验包元数据与加载标识、输入投影的回放与行渲染、文件行的失败/复制/手动兜底分支，全部通过后发布。面板与右侧栏的真实交互仍需在桌面端确认。
